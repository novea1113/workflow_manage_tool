# 工作序 · 個人工作排程

乾淨的工作排程管理工具。開啟時沒有預載工作、Sprint 或目標；可匯入原「工作序」工具匯出的 JSON 備份。

## 使用

網站：https://novea1113.github.io/workflow_manage_tool/

1. 在原工具中，按 **匯出備份** → **下載 JSON**，取得 JSON 檔案（下載受限時可改用複製備份內容）。這會包含該瀏覽器目前的全部年度的工作、Sprint 與目標。
2. 在公司使用的瀏覽器開啟上方網站，按 **匯入現有備份** 或 **匯入備份**，選擇剛才的 JSON。
3. 確認匯入筆數後，開始使用。匯入會取代目前資料，請先匯出既有資料。

不需要登入 ChatGPT 或 GitHub。網頁首次開啟為空白；不同裝置及瀏覽器各自保存資料。請使用 JSON 備份移轉，CSV 僅供檢視與報表，不支援還原。也可直接選擇原始 `.xlsx` Excel；只會讀取「個人工作紀錄-2026」分頁，匯入該分頁的工作、Sprint 與年度目標。

## 功能

- 新增年度並切換各年度的工項、Sprint 及年度目標。
- 新增、修改、刪除工項；各年度可新增 Sprint，跨年度可使用相同 Sprint 名稱。
- 年度目標可新增、修改、刪除或移至其他年度。
- Jira 連結有獨立欄位，點擊直接在新分頁開啟。
- Sprint 點數與容量、工作狀態、日期、JIRA、文件及備註。
- 清單、狀態看板、月曆，搜尋與篩選。
- JSON 備份匯入／匯出、篩選結果 CSV 匯出。
- 顯示備份中的工作目標。

## 資料儲存

使用瀏覽器 localStorage，鍵名為 `work-rhythm-clean-v1`，每次變更即儲存。資料不會傳送至 GitHub，也不會寫入這個 repository。程式沒有外部套件、分析服務、API 或後端請求。

網站程式碼與網址公開，但匯入的工作內容只存在使用中的瀏覽器。清除網站資料、換裝置、換網址或使用無痕模式可能失去資料，請定期匯出 JSON 備份。請勿將工作備份上傳到此公開 repository。

## 部署與本機啟動

純靜態 HTML、CSS、JavaScript，不需安裝套件或建置。

GitHub Pages：Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)` → Save。

本機開啟：

```sh
python -m http.server 8000
```

瀏覽 http://localhost:8000。也可下載原始碼後直接開啟 `index.html`（部分公司瀏覽器可能限制本機網頁儲存資料）。

## 備份格式

最外層為 `tasks`、`sprints`、`goals` 三個陣列。所有陣列均可為空。匯入會檢查工作狀態、日期與非負點數；支援原工具的同名 Sprint 分段紀錄，概覽會合計這些段落的容量。跨 Sprint 的工作以獨立紀錄保存，不以 JIRA 編號去重。

本 repository 僅含應用程式，沒有 Excel、工作紀錄、備份檔、帳號憑證或原 Sites 的部署識別資訊。

## 多年度版本升級

保留原 localStorage 鍵名，已有資料不需要重新匯入。舊工項依起始日期（無則結束日期）判斷所屬年度；沒有日期的工項與舊目標歸入備份中最多工作的年度，空備份則使用今年。每個工項、目標可在編輯視窗更改年度。Sprint 保留原分段紀錄，依相關工項年度歸屬。

新備份 `schemaVersion: 2` 含 `years` 陣列，工作、Sprint 和目標各自有 `year`，目標另有唯一 `id`。匯出包含全部年度；CSV 匯出為目前篩選的工項。匯入會取代全部年度，請先匯出現有備份。

匯出備份會開啟視窗，提供下載 JSON 與複製 JSON 兩條路徑；不會將資料傳送到伺服器。瀏覽器若限制剪貼簿，會選取全部 JSON，可按 Ctrl+C／⌘C 手動複製。舊版網站或其他 ChatGPT Sites 網址仍使用各自的儲存空間，請透過 JSON 移轉。

## 直接匯入原始 Excel

按「匯入 Excel／JSON」，選取原始 `.xlsx` 檔案，再確認筆數與取代提示。不需要先產生或下載 JSON，檔案不會上傳到伺服器；瀏覽器僅開啟「個人工作紀錄-2026」分頁。匯入會取代目前所有年度的資料，請先備份需要保留的紀錄。

Excel 匯入適用於原始紀錄格式，使用瀏覽器內建 ZIP 解壓縮與 XML 解析，不需外部套件或 CDN。保留合併儲存格的共用文件與日期，點數空白保留為未填；跨 Sprint 同名工項與重複 Sprint 分段均保留。需要支援 `DecompressionStream('deflate-raw')` 的新版 Chrome、Edge 等瀏覽器；不支援舊 `.xls` 或加密試算表。

## Sprint 備註

選擇年度與 Sprint 後，可在 Sprint 資訊下方填寫備註，例如休假日期、國定假日與容量扣點原因。輸入時會自動儲存；新增 Sprint 時也能先填備註。備註使用 Sprint 的 `notes` 欄位，隨 JSON 備份匯出、匯入。舊備份沒有此欄位時顯示空白；同名 Sprint 的分段紀錄各自保存備註。文字內容不會自動更改容量點數。

## 調整既有 Sprint 容量

選擇年度與 Sprint 後，按「編輯 Sprint」，可調整容量點數、期間說明及備註。儲存後立即更新概覽的容量分母與進度條，工作本身的點數保持原值。既有同名 Sprint 若包含多段，可在編輯視窗選擇分段，僅更新選取的那一段。年度與 Sprint 名稱在編輯時固定，維持現有工作關聯。
